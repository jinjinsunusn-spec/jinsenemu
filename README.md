# 精森天翼配點模擬器

TalesWeaver 重練配點模擬器（網頁版）。直接開啟 `index.html` 即可使用，不需要安裝。

## 授權與出處

本專案改作自 [rugumaxi/oresim-flash](https://github.com/rugumaxi/oresim-flash)（ルグ鯖某マキシ，俺シミュ Flash PC 版），依 Apache License 2.0 授權，授權全文見 `LICENSE`。

主要修改：

- 將原本的 ActionScript（Flash）程式改寫為 JavaScript 網頁版
- 介面與記錄、配方改為繁體中文
- 等級上限 310、能力值上限 500、HP 上限 40000
- 265 級以後每級點數調整（265–280：9、281–290：10、291–300：11、301–310：50）
- 部分角色型態的初始消耗點數調整
- 新增降級、整段上一步／下一步、角色圖片等功能

遊戲名稱、角色名稱及相關數據之權利屬於原遊戲公司。
